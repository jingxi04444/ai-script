# 快手短链接文案提取调研与接口说明

## 调研结论

快手分享链接提取文案包含两个独立步骤：

1. 解析短链重定向和页面状态，获得目标作品的视频直链与作品配文。
2. 下载视频音轨并通过 ASR 提取视频中的语音文案。

OpenAI 官方可安装 Skill 清单中没有快手专用 Skill，只有通用的 `speech` 和 `transcribe`，无法独立完成第一步。

可参考的开源实现：

- [video-batch-download](https://github.com/ljb1020/video-batch-download)：MIT License，可作为 Agent Skill 使用；支持快手短链、按作品 ID 精确绑定 Apollo/GraphQL 详情、Playwright 捕获媒体流和 faster-whisper 本地转写。它的完整性最高，但直接接入会新增 Node.js、Chromium、Python、ffmpeg 和模型文件等运行依赖。
- [KS-Downloader](https://github.com/JoeanAmier/KS-Downloader)：快手专用下载器，支持短链和 API 服务，解析能力成熟；不包含语音转写，且采用 GPL-3.0，不宜直接复制源码到当前项目。
- [video-downloader](https://github.com/httprunner/video-downloader)：Go 实现的多平台下载器，提供 REST API，支持 `v.kuaishou.com`；主要解决下载，不负责 ASR。
- [koishi-plugin-video-parser-all](https://github.com/Minecraft-1314/koishi-plugin-video-parser-all)：支持快手的 Koishi 插件，但依赖统一第三方解析 API，也不包含 ASR。
- [yt-dlp 快手支持 issue](https://github.com/yt-dlp/yt-dlp/issues/14010)：截至调研时仍不能把 yt-dlp 视为稳定的快手解析方案。

当前实现没有引入上述项目的运行时或复制其源码，而是复用项目已有的 `VideoParserClient`、`AsrClient` 和 Provider 配置。快手页面状态解析增加了按重定向后作品 ID 精确匹配的保护，避免把推荐流中的其他视频当成目标作品。

## 接口

`POST /api/video/kuaishou/transcript`

该接口需要登录，接受纯链接或包含链接的整段快手分享文本。接口会同步完成短链解析、视频处理和 ASR，并直接返回文案结果。

请求示例：

```json
{
  "url": "复制打开快手，看看这个作品 https://v.kuaishou.com/xxxxxx"
}
```

成功响应示例：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "platform": "kuaishou",
    "shareUrl": "https://v.kuaishou.com/xxxxxx",
    "resolvedUrl": "https://www.kuaishou.com/short-video/作品ID",
    "videoUrl": "https://视频CDN地址.mp4",
    "title": "作品标题",
    "authorName": "作者昵称",
    "coverUrl": "https://封面地址",
    "caption": "发布者填写的作品配文",
    "transcript": "ASR 提取的视频语音文案",
    "transcriptSource": "asr"
  },
  "traceId": "请求链路ID",
  "timestamp": 1710000000000
}
```

## 运行要求和边界

- 必须在系统 Provider 配置中启用一个 `asr` Provider。
- 如果 ASR 地址是 OpenAI 兼容的 `/audio/transcriptions` 接口，服务端还必须安装 `ffmpeg`；服务会先下载视频、提取单声道 16 kHz 音频，再上传 ASR。
- `video_parse` Provider 是可选的；未配置时使用项目内置解析器。
- 仅接受 `kuaishou.com`、`kuaishou.cn`、`gifshow.com`、`ksurl.cn` 及其子域，防止把接口变成任意 URL 抓取器。
- 接口只提取语音和作品配文，不识别画面中的字幕。画面文字需要另接 OCR 流程。
- 作品删除、私密、短链失效或触发快手验证码/风控时会返回统一业务错误；没有绕过平台访问控制。
- 视频直链通常带有效期，不应长期缓存；如需任务化和持久化，可继续使用现有项目解析任务流程。
- 该接口是同步接口，调用方和反向代理的读取超时时间需要覆盖视频下载、ffmpeg 音频处理和 ASR 耗时。
