# 创意资源库：角色 / 风格 / 特效

## 已完成的第一版

前台画布入口：底部「素材与图片」、添加节点菜单、右键菜单，以及角色/风格/特效节点的资源面板。

后台入口：「资源与模板 → 创意资源库」，路由 `/admin/creative-resources`。开发预览可使用 `http://127.0.0.1:4176/admin/creative-resources`；现有管理员账号登录后访问。

- 后台维护名称、稳定编码、分类、封面、多视图、预览视频、标签、提示词、负向描述、JSON 模板配置、排序、作者和授权说明。
- 新建、编辑、复制为新草稿、上下架、软删除；上传图片/视频后需保存资源。删除不删除媒体文件，避免破坏旧工作流引用。
- 前台展示已发布条目，支持搜索、分类、分页、网格/列表、详情预览、角色设定板、可选视频预览。
- 收藏与最近使用是**按账户隔离的本机浏览器记录**，不是跨设备同步。收藏最多48项，最近使用24项。
- 选中图片或视频节点，再从库中「应用并连接」，会同时添加资源节点、连线和引用关系；角色套图会逐张添加并分别连接、引用。普通导入只添加独立资源节点，不自动连接生成节点。
- 三类都是资源节点，没有生成输入框；输入框与模型选择留在文本/图片/视频/音频生成节点。资源可替换，画布原有删除/撤销操作继续适用。

资源是一个包含媒体与模板的结构，而不是一张封面图，也不是可执行的 Python 插件：

| 类型 | 首批内容 | 下游收到什么 |
| --- | --- | --- |
| 角色 | 林沐、陈屿：全身图、面部特写、表情九宫格、多角度设定图，另保留旧综合设定板 | 人物设定、负向描述与已连接的独立图片；整套导入每位5张，移除某张后不再传递该图 |
| 风格 | 柔光日常、琥珀映画 | 摄影参考图、光线/色彩描述和负向约束 |
| 特效 | 产品环绕运镜、水花慢动作 | 运镜/特效提示词与参考参数；**不把封面或预览视频当输入帧** |

## 角色四图套装维护

角色不再只展示一张封面。标准套图固定为四个独立槽位：`全身图`、`面部特写`、`表情九宫格`、`多角度设定图`，仍使用已有 `gallery: [{label,url}]` API 字段，没有增加数据库列。

- 后台角色列表展示「角色套图 n/4」和四格缩略图，可打开「整套角色预览」。宽屏预览并排显示四张参考图，使用 `object-fit: contain` 保留人物全身与设定板画面。
- 角色编辑器顶部同时显示四个维护槽位，每个可以单独粘贴 URL、上传、替换和移除。封面缩略图仍独立维护；移除面部特写不会从封面自动补回。
- 四图之外的旧综合设定板、其他服装等放在「额外参考」区域。独立套图与额外参考合计最多12张。
- 兼容旧标签 `独立肖像`、`独立肖像参考`、`肖像特写`、`肖像`，仅映射面部特写，识别时忽略标签首尾空白。旧的「正侧背与六种表情」混合设定板只算额外参考，不冒充独立九宫格或多角度图。
- 缺图明确显示待补充，不重复使用同一张图自动填槽。草稿允许缺图；套图完整性只提示，不改变现有发布 API 的名称、分类、封面、提示词和授权说明校验。

本轮两个角色现已具备**全身图、面部特写、表情九宫格、多角度设定图，完整度均为4/4**，各自另保留旧综合设定板。新增 `character-lin-expressions.png` 和 `character-chen-expressions.png` 均为1254×1254的独立九宫格，已同步前后台公共目录、catalog 和安装 SQL。`config.referenceViews` 列出实际四图与额外设定板，已移除 `pendingReferenceViews` 缺项标记。

生成历史：两人的九宫格最初各因外部生成服务网络错误失败两次，当时停留在3/4，未用占位图冒充成功；本轮随后仍使用同一内置 `image_gen`，各自以已有独立肖像为参考补生成成功。此前失败、后续成功、精确提示词和引用图均保留在下方生成记录中。这一历史阻塞已解除，不再是当前未完成项。

## 角色套图在画布中的交互

- 从角色库应用时，将 `gallery` 中有效地址去重后的图片逐张展开为独立的 `character` 资源节点，标准四图和额外参考均会导入；封面与套图重复时不会额外添加。没有 gallery 的旧角色资源才回退为单张封面。
- 每个节点标题为「角色名 · 视图名」，`assetUrl`、`resourceCoverUrl` 与仅含一张图片的 `resourceGallery` 指向该节点自身图片；同时保留来源资源 ID、角色身份配置、提示词与负向描述，不把其他图片隐藏在单图节点中传给下游。
- 整套导入只记一次撤销记录，新导入的图片一起选中并按明确的套图边界定位到可见画布，不依赖新节点异步测量。若候选位置与已有节点相交，套图放到已有内容右侧空位，不覆盖旧节点。一次撤销可以撤回整套导入。
- 每张图片右上角的 X 只删除当前节点，即使同时选中了整套图片也不连带删除。删除同时清理该图相关的参考、标记与连线，不影响资源库原素材、同角色的其他图片或其他角色；可通过撤销恢复。
- 「更换此图」只替换当前节点，优先使用新角色中与当前视图同名的图片；若没有对应视图则使用首张有效图片。保留当前节点 ID 和连接，不替换或删除同套其他图片。
- 保存与重载保留各张独立节点，已经删除的图片不会从角色库自动补回。已有项目不会静默迁移；从旧式整套角色节点或空角色占位节点打开库时，操作为「应用整套角色」，展开所有图片。首图保留原节点ID，并将原有下游引用/连线扩展至所有视图；一次撤销恢复旧结构。已经拆分的节点「更换此图」仍只换一张。
- 角色弹窗独立固定深色主题，包括输入、筛选、原生下拉与禁用翻页按钮，不受全站浅色兼容规则影响；应用主按钮保留白色强调。

## 真实能力边界

特效首批提供的是提示词模板和静态效果示意图，不是已渲染的视频素材、LoRA 权重、3D 模型或保证还原的特效引擎。后台已支持上传真实 MP4/WebM 预览。配置为 JSON 数据，不执行代码、不加载模型权重、不允许覆盖下游 Provider URL/密钥/模型参数。

Python `CreativeResourceSkill` 在真实和演示模式均传递实际资源快照；只有 `identity/wardrobe/lighting/palette/cameraMotion/durationSeconds/strength/preserveSubject` 会转成可读提示词说明，其余配置保存在画布中供后续适配使用。时长和强度在这里是创作描述，不强制覆盖生成节点参数。

现有 Spring Provider 网关会把资源描述合并进下游提示词，把角色/风格图片传给图片生成适配器。现有视频适配器仍以提示词驱动，**不能据此宣称视频模型已实现人物图像一致性输入**；是否支持参考图由具体供应商协议决定。本轮未通过工作流调用真实供应商图片/视频模型验证生成效果，也未开启 runner 真实网关。

示例素材由内置 `image_gen` 制作，初版8张、本轮新增4张全身/多角度图及2张九宫格，目前共6套资源、14张PNG，不复用 LibLib 截图素材。本轮补图没有修改业务代码，也不等同于工作流真实图片/视频模型端到端验证。人物为原创虚构成年人。角色多视图用于参考，不能保证所有模型自动保持身份。发布前仍需内容与适用授权审核，没有标记“已获商用认证”。生成提示词记录见 [creative-library-image-prompts.json](./creative-library-image-prompts.json)。

## 资源文件与数据库

- 主资源目录：`web/front-web/public/creative-library/`，包含 `catalog.json` 和14张PNG。
- 后台预览副本：`web/admin-web/public/creative-library/`，同步相同 `catalog.json` 与14张PNG。后台实际列表仍请求管理员 API，不使用静态目录假装数据库结果。Vite 基路径是 `/admin/`，预览时适配路径，数据库保持 `/creative-library/...` 的标准地址。
- 平台公共目录表：`sys_creative_resource`；不与租户私有 `ai_asset` 混用。
- ID 使用 BIGINT / Long / ASSIGN_ID，响应 ID 为字符串。稳定 `code` 唯一，创建后不可修改，删除后也不复用。
- 本次已在核实的本地 `localhost:3306 / ai_script` 新建表并导入6条示例，重跑后仍为6条；没有覆盖旧业务数据或修改账号。
- 其他环境先执行 `doc/global-database/mysql/migrations/20260905120000_creative_resources.sql`，再执行 `20260905121000_creative_resources_seed.sql`；不要用全量建库脚本更新已有库。
- 增量种子只在 code 和 ID 均未占用时插入，不覆盖管理员维护值、不复活已删除条目。全量建库/初始化文件也已包含相同结构与示例。
- 新安装数据的主 seed 和 `20260905121000_creative_resources_seed.sql` 已同步本轮四张标准视图与旧综合板；重跑它们不会更新已存在的旧角色。

旧安装可在备份并确认目标库后，人工评估独立迁移 `doc/global-database/mysql/migrations/20260906120000_character_reference_sets.sql`。本轮只准备文件，**未执行该 SQL，也不覆盖已经通过后台维护的角色**。脚本先输出每个角色的候选数，再尝试升级，最后输出实际更新行数；每条最多一行。

安全升级需要同时满足：原始固定 ID 和编码、类型为角色、未软删除、创建人/修改人为空、创建时间等于修改时间，以及全部可编辑字段与旧安装种子一致。文本使用二进制比较，JSON 使用结构比较。任何后台编辑、下架、软删除、旧值差异都会跳过，已升级或新安装记录再次执行也跳过。仅更新描述、gallery 和 config，不修改封面、提示词、发布状态、作者或授权。被跳过的自定义角色请用后台四槽编辑器手工维护。

模板与资源媒体被复制为工作流节点快照，后台更新/下架不会偷偷改变旧项目。前台每次应用前重新检查资源仍已发布；下架影响新的选择，旧图中的快照仍保留可复现性。

首批文件是静态站内路径，浏览器可直接预览。**远程模型不能访问本机相对路径**：投入真实生成前，请通过后台上传到公开可访问的对象存储，或更新为供应商能访问的完整 HTTPS 地址。不要把 localhost 地址交给外部供应商。

本轮通过现有管理员会话，在真实维护页面先保存了林沐、陈屿的独立全身图、多角度图、面部特写标签、额外参考名称及引用配置；九宫格补齐后，又分别编辑新增九宫格、更新描述并移除待补标记。保存已发布资源并点击刷新后，两项实际均显示 **4/4**，旧综合设定板仍作为额外参考保留；未改变原来的封面、提示词、作者、授权与发布状态。未运行上述升级 SQL，未修改其他角色或风格/特效记录。

## API

统一使用项目的 `R<T>` / `PageResult<T>` 返回格式。

| 方法 | 地址 | 行为 |
| --- | --- | --- |
| GET | `/api/creative-resources` | 登录用户分页读取已发布目录 |
| GET | `/api/creative-resources/{id}` | 已发布详情；草稿/下架/删除返回不可用 |
| GET | `/api/admin/creative-resources` | 管理员分页读取，含草稿 |
| POST | `/api/admin/creative-resources` | 新建 |
| PUT | `/api/admin/creative-resources/{id}` | 编辑、上下架、排序 |
| DELETE | `/api/admin/creative-resources/{id}` | 软删除 |

列表参数：`page/pageSize/keyword/type/category`；后台另有 `status`。类型为 `character/style/effect`，状态为 `draft/published`。用户端不能利用 status 查询草稿。管理员接口在安全过滤链之外，服务方法还会验证管理员身份。

发布要求名称、分类、封面、提示词、授权说明；草稿允许尚未完成的封面和提示词。媒体URL只接受HTTP(S)或站内绝对路径，不接收data/blob/javascript、带凭据的URL。图片存在性与授权真实性仍需人工确认。JSON为有界数据，限制16000字节、深度8、每层100项；标签20个、画廊12张。
